# 📈 Stock Portfolio Tracker Pro

A simple and interactive Python-based stock portfolio tracker that calculates total investment using predefined stock prices.

## 🎯 Project Objective

The goal of this project is to build a simple stock tracker that allows users to enter stock names and quantities and calculates the total investment value.

## ✨ Features

- 📊 Predefined stock price dictionary
- 💰 Calculate investment for each stock
- 📈 Calculate total portfolio investment
- 🏆 Identify the highest investment stock
- 🔄 Add multiple stocks
- ❌ Input validation and error handling
- 📄 Generate a TXT portfolio report
- 📊 Generate a CSV portfolio report
- 🖥️ Clean and interactive terminal interface

## 🛠️ Technologies Used

- Python
- Dictionary
- Input / Output
- Arithmetic Operations
- File Handling
- Exception Handling
